# Anatomia da Crosser 150 (2023)

Modelo 3D interativo da Yamaha Crosser 150 preta, feito com [three.js](https://threejs.org).
Clique numa peça para isolá-la e ver para que serve; peças com "ver por dentro" mostram as partes internas explodidas em 3D.

**Abrir:** https://pedrotexb.github.io/crosser-150/

- Um único arquivo (`index.html`) com three.js e fontes embutidos — funciona até offline.
- Funciona no computador e no celular.
